# 进度文件格式与恢复

路径是应用目录下的 `data/progress.txt`。首次无文件按空表初始化；空文件不是有效进度文件。

前两行固定为 `CJPROGRESS1` 和十进制记录数。每条记录固定八行，依次为：

| 行 | 字段 | 规则 |
|---:|---|---|
| 1 | userId | 非空内部账号 ID；旧 practice 记录仍属于 practice |
| 2 | packageId | 非空题包 ID |
| 3 | problemId | 非空题目 ID |
| 4 | sourcePath | 用户原源码绝对路径，可为空 |
| 5 | status | 0 未开始、1 练习中、2 本地通过 |
| 6 | lastSummary | 最近有效结果的单行摘要，可为空 |
| 7 | lastOpenedTime | 最近记录的打开/绑定时间，可为空 |
| 8 | lastJudgedTime | 最近有效判题时间，可为空 |

空字段仍占一行，记录之间没有额外分隔行。读取接受 LF/CRLF；保存为 UTF-8、LF。记录数之后不能有额外行。三项 ID 组合不能重复。当前解析器不接受文件头 BOM；编辑时勿自动添加 BOM。

`load()` 先校验完整候选集合，成功才替换内存。失败保留旧集合及文件，但禁止查询和保存，直到修复并重新成功加载。`getProgress()` 找不到已有记录时返回指定三项 ID 的默认未开始记录；返回的记录及 `getUserProgress()` 集合都是副本。

`saveProgress()` 按三项 ID 在候选副本中新增或替换，用 `QSaveFile` 写临时文件，关闭直接覆盖回退；提交成功后才更新内存。写入字段不能含换行。有效 AC 更新为本地通过；WA、CE、RE、TLE、OutputLimit 更新为练习中；InternalError 不覆盖原有效记录。

移动整个应用目录时带上整个 `data/`。缓存题目的路径在加载时重新计算；源码路径仍保存原绝对路径，源码另行移动后需重新绑定。

异常检查必须使用独立运行副本。先关闭程序，再备份有效 `progress.txt`；把第一行改为 `WRONG`，启动应报标识错误且不覆盖文件。关闭后用备份原样恢复，再启动检查旧记录。不要用删除文件代替恢复。

保存失败检查：程序已启动且绑定好源码后，在另一个 **PowerShell** 窗口独占锁定文件，保持锁定，再判题。预期结果仍可见并提示保存失败；解锁后逐字节比较原文件，再重启核对旧状态。锁定及比较命令见 `a-week45-validation.md`。
