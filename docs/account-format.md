# 账号格式与兼容约定

应用目录下 `data/accounts.txt` 的前两行是 `CJACCOUNTS1` 和账号数（0～1000）。每个账号固定六行：内部 ID、用户名、算法名 `PBKDF2-SHA256`、迭代次数 `600000`、盐的 32 位小写十六进制、验证值的 64 位小写十六进制。不保存明文密码，不将口令写入日志。

新用户名为 3～20 位 ASCII 英文字母、数字或下划线，按原样区分大小写与查重，不静默裁剪空格。新内部 ID 从 u0001 起分配，逐个检查已有 ID，避免和历史 ID 冲突。每账号使用系统随机源产生 16 字节盐，通过 Qt PBKDF2-HMAC-SHA256 派生 32 字节验证值。

加载后登录按用户名查记录，再用保存的盐和参数重新派生并比较。成功返回内部 ID；显示名和进度身份分开。已有会话必须退出后才能换账号，失败不修改 ID 输出参数。注册先保存候选集合，文件提交成功才更新内存。

旧版每行“用户名 密码”的文件在整份校验后原子转换；旧账号保留原用户名值作为历史内部 ID，因此原进度仍能命中，无需冒险同时迁移两个文件。转换后该 ID 不随显示名改变；本版没有改名功能。新账号总是生成独立 ID，旧 practice 进度不自动分配给新账号。

旧用户名不符合新版规则、字段残缺、重复账号或转换保存失败，均停止加载并保留原文件，不跳过坏记录、不创建空表覆盖。不要直接编辑格式或清空旧数据；首次升级前可自行备份整个 data 目录，备份可能仍含旧明文密码，应由用户保管，勿提交仓库或装进发布包。

首次无文件时原子创建带标识的空表。已存在但不可读的文件不会被当成首次运行。新格式只接受上述固定算法参数及六个完整字段，拒绝多余内容；修复后重新启动。

注册窗口首次点击注册进入注册模式，显示确认密码框；第二次点击确认注册才提交。两个密码不一致时留在窗口，返回登录隐藏确认框。退出清空个人结果和筛选，判题中禁止退出、切换账号及更改绑定。

参数来源：[Qt QPasswordDigestor](https://doc.qt.io/qt-6/qpassworddigestor.html)、[Qt 系统随机源](https://doc.qt.io/qt-6/qrandomgenerator.html)、[OWASP Password Storage](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)。Qt Network 在本项目用于本地密码派生，不代表程序需要联网。
