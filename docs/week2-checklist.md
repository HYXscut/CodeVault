## 使用方法

- `run-test.cmd`：双击后执行全部八次，保留控制台窗口。
- `run-test.cmd AC`、`WA`、`CE` 或 `TLE`：只执行指定分支。
- Qt Creator 运行 `JudgeEngineTest` 时，参数填写 `D:/Qt/Qt/Tools/mingw1510_64/bin/g++.exe ALL`，也可把 ALL 换成单个状态。
- 测试程序退出码 0 表示实际状态符合预期；预期 CE 或 TLE 的测试也应返回 0。
