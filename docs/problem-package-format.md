# 题包格式与正式演示题

题包是一个文件夹，包含 `package.txt` 以及每题独立的子目录。文本使用 UTF-8；建议无 BOM、LF 换行并保留末尾换行。题面按普通文本显示，不要求 Markdown 渲染。

`package.txt` 前四行分别是格式标识 `CJPKG1`、题包 ID、非空题包标题、题目数量（1～200）。接下来每题固定五行：题目 ID、非空标题、分号分隔的标签、时限毫秒（100～10000）、测试点数（1～20）。没有 difficulty 字段；无标签时第三行为空，不可省略该行。

例如 `samples/week3_demo/package.txt`：

```text
CJPKG1
week3_demo
第三周多点验收
1
P001
A+B 求和（五点）
入门;整数;多测试点
1000
5
```

包 ID 与题目 ID 只允许 ASCII 字母、数字、下划线、连字符。题号在一个包内唯一，不同包可以复用。元数据行数必须恰好为 `4 + 题数 × 5`，不插入分隔空行。

每题目录名为题号，内含 `statement.md` 和 `1.in/1.out` 到 `N.in/N.out`。编号不能跳号，不能使用 `01.in`，不能有多余 `.in/.out`。测试文件按原始字节读取，空文件合法；测试输入和标准输出必须配对。非空标签不能含空段，如 `入门;;循环` 非法。

正式演示使用已有四题，不用 50 道重复记录代替正式题：

| 包/题 | 内容 | 测试点数 | 用途 |
|---|---|---:|---|
| demo/P001 | A+B 求和 | 2 | 前两周流程回归 |
| demo/P002 | 两整数最大值 | 1 | 条件判断、负数 |
| demo/P003 | 1 到 n 求和 | 1 | 循环、整数运算 |
| week3_demo/P001 | A+B 求和 | 5 | 全 AC、第三点 WA、首错停止 |

五点题第三点输入首数为 0，`examples/answer_wa_at3.cpp` 只在这里故意出错。其他状态源码见 `examples/answer_ce.cpp`、`answer_re.cpp`、`answer_tle.cpp`、`answer_output_limit.cpp`；正确源码为 `answer_multi_ac.cpp`。

导入先验证原包，再复制到 `.importing-*` 临时目录、校验副本、改名保存。外部原题包不修改。已显示包重复导入失败；已隐藏包必须在元数据、题面及全部声明测试文件逐字节相同时才能恢复。BOM 或换行变化也属于内容变化。同 ID 改版应使用新 ID。

只隐藏共享题包，不手工删除 `data/packages/<包ID>`；隐藏后缓存仍是恢复时比较内容的依据。
